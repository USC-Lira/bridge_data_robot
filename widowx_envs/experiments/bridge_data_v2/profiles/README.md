# Keyboard controls profiles

Put your keyboard profiles here (`.yaml`, `.yml` or `.json`) and use them from a
conf by name: `teleop_profile="my_keys"` finds `profiles/my_keys.yaml`.

A profile lists only what differs from the default layout; see
`../keyboard_profile_example.yaml` for the format and
`widowx_envs/widowx_envs/teleop_profiles.py` for the defaults.

This folder is also reachable as `configs/profiles/` from the repo root.
